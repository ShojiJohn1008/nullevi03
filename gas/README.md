# カレンダー橋渡し (Google Apps Script) の導入

`gcal.py` から Google カレンダーを読み書きするための、Apps Script ウェブアプリの設置手順。
**Google Cloud の OAuth 設定は不要**。自分のアカウントの中でスクリプトが自分の権限で動く。
一度公開すればトークンの失効もなく、会話秘書 (boot.sh) からも朝の自動実行からも使える。

## 1. スクリプトを作る

1. ブラウザで <https://script.google.com> を開き「新しいプロジェクト」
2. 名前を付ける (例 `ナルエビ-calendar`)
3. 既定の `Code.gs` の中身を全部消して、`gas/Calendar.gs` の内容を丸ごと貼り付けて保存

## 2. 合言葉を設定する

コードに秘密を書かず、プロジェクト側に持たせる:

1. 左の歯車「プロジェクトの設定」を開く
2. 「スクリプト プロパティ」→「スクリプト プロパティを追加」
3. プロパティ名 `SHARED_SECRET`、値は**自分で決めた長めの合言葉**(推測されにくい文字列)を入れて保存

この合言葉は、あとで `.env` の `CAL_SHARED_SECRET` に**同じもの**を入れる。

## 3. ウェブアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」
2. 種類の歯車 →「ウェブアプリ」を選ぶ
3. 設定:
   - **次のユーザーとして実行: 自分 (Me)**
   - **アクセスできるユーザー: 全員 (Anyone)**
     ※「全員」でないと、ローカルスクリプトから合言葉だけで叩けない。認証はスクリプト内の合言葉チェックで行う
4. 「デプロイ」を押す

## 4. 一度だけ承認する

初回は「このアプリは Google で確認されていません」と警告が出る (自分専用アプリなので正常):

1. 「詳細」→「(プロジェクト名) に移動 (安全ではないページ)」
2. カレンダーへのアクセスを「許可」

これで、あなた自身の権限がこのウェブアプリに紐づく。

## 5. URL を控えて .env に入れる

公開後に表示される **`https://script.google.com/macros/s/.../exec`** の URL をコピーし、`.env` に:

```
CAL_WEBAPP_URL=https://script.google.com/macros/s/xxxxx/exec
CAL_SHARED_SECRET=手順2で決めた合言葉と同じもの
```

## 6. 動作確認

```sh
# 生存確認 (ブラウザで /exec を開くと {"ok":true,...} が出る)
# ローカルから今日の予定一覧:
python3 gcal.py list 2026-07-10
```

`{"ok": true, ...}` が返ればOK。`unauthorized` なら合言葉の不一致、
接続できないなら URL を確認。

## あとでコードを直すとき (重要)

コードを編集しても、公開中のアプリには自動反映されない。**URL を変えずに更新**するには:
「デプロイ」→「デプロイを管理」→ 対象の**鉛筆(編集)**→ バージョンを「新バージョン」→「デプロイ」。
「新しいデプロイ」を押すと URL が変わってしまうので注意。

## できること

- `calendars` … 見えているカレンダーの一覧 (共有・購読を含む。ID 調べ用)
- `list` … 指定期間の予定を返す (空き確認・日程調整に使う)。メイン + 指定した共有カレンダーを合算
- `hold` … 「【仮】」付き・灰色の仮押さえを作る (返事待ちの二重ブッキング防止)
- `create` … 通常の予定を作る
- `delete` … イベントIDで削除

### 共有カレンダーも見る

1. `python3 gcal.py calendars` で、アクセスできるカレンダーの ID 一覧を出す
2. `.env` の `CAL_EXTRA_CALENDAR_IDS` に、見たい共有カレンダーの ID をカンマ区切りで書く
3. 以降 `gcal.py list` はメイン + それらを合算して返す

書き込み先を共有カレンダーにしたいときは `.env` の `CAL_WRITE_CALENDAR_ID` に ID を入れる
(その共有カレンダーに「予定の変更権限」が必要)。

他人へゲスト招待を送る機能は入れていない (通知が飛ぶ操作なので、必要になったら確認フロー付きで足す)。

## コードを更新したら再デプロイを忘れずに

この `Calendar.gs` を貼り替えたら、**URL を変えずに更新**するため
「デプロイ」→「デプロイを管理」→ 鉛筆(編集)→ バージョン「新バージョン」→「デプロイ」。
